# 교민 결정 데스크 · 카드뉴스 메이커

인도네시아 교민에게 필요한 뉴스를 인스타그램 카드뉴스로 만드는 단일 파일 도구.

포지션: **"인도네시아에 사는 한국인이 이번 주에 무엇을 해야 하는지 알려주는 브랜드"**

## 구조

```
index.html       단일 파일 도구. 배경 이미지까지 base64로 인라인
robots.txt       검색 색인 차단
images/          배경 원본 사진
README.md
```

이 저장소는 **공개(public)** 이다. 커밋하는 모든 것이 인터넷에 공개된다고 보고 다뤄야 한다.

`brand-kit.txt`(포지션·경쟁 분석·타겟 정의가 담긴 내부 문서)는 그래서 **`.gitignore` 대상**이며
로컬에만 둔다. 저장소를 비공개로 바꾸면 `git add -f brand-kit.txt`로 추적에 넣을 수 있다.

앞으로 내부 문서를 추가할 때도 같은 방식으로 `.gitignore`에 넣는다.
(`.vercelignore`는 Vercel CLI에서만 동작하고 Git 연동 배포에는 적용되지 않으므로 쓸 수 없다.)

## 로컬에서 열기

```
index.html
```

브라우저로 바로 열면 된다. 빌드도, 서버도 필요 없다.

## 기능

포스팅 1건 = 기사 1건 = **카드 5장** (표지 · 내용 3 · 마무리)

- 1080×1350(기본) / 1080×1080 규격 전환
- 카드 한 장에 **큰 제목(최대 2줄) + 세부 설명(최대 4줄)**이 함께 들어간다.
  제목이 길면 자동으로 작아지고, 설명 줄 수는 남은 공간에서 계산되어
  하단 표기와 겹치지 않는다
- 하단에 **출처와 기사 일자**를 고정 표기. 5장 전체가 같은 값을 쓰므로
  조절판에서 한 번만 입력한다
- 출처나 기사 일자가 비면 경고 표시
- 조절판: 폰트, 글자 크기, 배경색 3종, 배경 이미지, 오버레이 농도
- 추천 배경 3종 내장 + 카드별 기본 배분
- 내 이미지 여러 장을 파일명 순서로 카드에 일괄 배분
- 카드별 / 전체 PNG 저장, 문구 JSON 복사
- 작업 내용 localStorage 자동 저장

## 폰트

| 용도 | 폰트 | 라이선스 |
|---|---|---|
| 제목 | G마켓 산스 | 상업용 무료 · https://corp.gmarket.com/fonts/ |
| 본문 | Pretendard | SIL OFL 1.1 · https://github.com/orioncactus/pretendard |

G마켓 산스는 서드파티 CDN에서 불러온다. 안정적으로 쓰려면 공식 배포처에서 받아
`site/fonts/GmarketSansBold.woff2` 등으로 넣으면 그쪽을 먼저 사용한다.
(`site/fonts/`는 `.gitignore` 대상이므로 각 작업 PC에서 개별로 넣는다.)

## 배포

Vercel Git 연동. `main`에 푸시하면 자동 배포된다.

`index.html`이 저장소 루트에 있어서 **Vercel 설정이 필요 없다.** 프레임워크 없음으로
감지되어 정적 파일 그대로 서빙된다. Root Directory도 기본값을 그대로 두면 된다.

기능을 추가하면 커밋·푸시가 곧 배포다. 별도 빌드 단계가 없으므로 푸시 후
1분 내에 프로덕션에 반영된다.

## 발행 전 체크

- [ ] 기사에 나온 날짜·금액·기한을 원문과 대조
- [ ] 출처(매체·기관)와 기사 일자 입력 (경고 표시가 없어야 함)
- [ ] 제목이 잘리지 않았는지 (2줄 상한, 초과분은 `…`)
- [ ] 설명이 잘리지 않았는지 (남은 공간에 따라 1~4줄)
- [ ] 해시태그는 5개 이하 (플랫폼 상한)
- [ ] 5번 카드에 공유 유도 문구 유지
